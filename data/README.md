# Input data (not redistributed)

Download the following four public NCBI GEO supplemental files from the original accession pages. Put all four directly into a local input directory, e.g. `local_inputs/` outside the git-tracked repository.

- P5: [GSM8855707](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM8855707): `GSM8855707_NSCLC_P5_filtered_feature_bc_matrix.h5` and `GSM8855707_NSCLC_P5_spatial.tar.gz`
- P12: [GSM8855714](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM8855714): `GSM8855714_NSCLC_P12_filtered_feature_bc_matrix.h5` and `GSM8855714_NSCLC_P12_spatial.tar.gz`

Series: [GSE292299](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE292299).

The counts represent independent advanced NSCLC tissue specimens. They are not early-stage, premalignant or benign nodules and are not samples from the DKFZ PRELUNG study.

The repository contains code, summaries and derived figures, **not** raw images, raw matrices, patient-level metadata, DNA or clinical datasets.
